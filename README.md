## 🚀 About Me

From the mountains of **Cali, Colombia** to the tech hub of **Munich, Germany**, my journey has been anything but conventional. I started as a **Certified Environmental Engineer** (2013), driven by a passion for sustainability, and evolved into a **Computer Science Ph.D.** (2022) obsessed with distributed systems and high-performance computing.

Since 2015, I've been an active **open source contributor and maintainer**, working at the intersection of cloud-native technologies and scientific computing. Today at **NVIDIA**, I focus on enabling specialized hardware—GPUs, fast networks, and accelerators—in Kubernetes environments, making cutting-edge compute accessible through containers.

> 💡 **My Mission**: Enable scientists and researchers to run mathematical simulations and data analysis on cloud infrastructure with the same power and ease as traditional HPC systems.

---

## 🔭 Current Work

As a maintainer of several **kubernetes-sigs** projects, I'm focused on:

- 🎯 **GPU Enablement in Kubernetes** - Making specialized hardware first-class citizens in cloud-native workloads
- 🔌 **Node Feature Discovery** - Automatically detecting and advertising hardware capabilities
- 📊 **Job Queueing (Kueue)** - Fair resource sharing for batch workloads and ML training
- 🌐 **MPI Operator** - Running distributed HPC applications on Kubernetes
- ⚡ **Fast Networks** - Optimizing RDMA, InfiniBand, and high-speed networking for containerized workloads
